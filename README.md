# 📘 ED1 — Linked Lists — List 07

Practice exercises for **Data Structures I** — algorithms on singly linked lists in C++ (sorted insertion, deletion without predecessor, in-place reversal, merge of sorted lists, and removal of the n-th node from the end).

## 📁 Project Structure

```
ed1-linked-list-list07-cpp/
├── cmake-build-debug/
├── include/
│   ├── LinkedList.h
│   └── List.h
├── src/
│   ├── Exer01_AddSorted.cpp
│   ├── Exer02_DeleteNodeWithoutHead.cpp

│   ├── Exer04_MergeTwoSortedLists.cpp
│   └── Exer05_RemoveNthFromEnd.cpp
├── .gitignore
├── CMakeLists.txt
├── main.cpp
└── README.md
```

> **Note:** `main.cpp` at the project root is the default file created by CLion. It is **not part of the exercises**. `cmake-build-debug/` is generated by the IDE.

The list structure lives in `include/`, and each exercise is solved in its own file inside `src/`. Every `Exer*.cpp` file is **self-contained** (has its own `main()`) and follows the same pattern:

| Part | Responsibility |
|---|---|
| `class Solution` | Implements the algorithm, using the `LinkedList` structure. |
| `main()` | Runs the test cases and prints each `Output` next to its `Expected` value. |

> **About `Solution`:** `LinkedList` declares `friend class Solution;`, so the `Solution` class can access `head`, `tail`, `count` and the `Node` type, which are private. Any other code still cannot touch them.

## 📝 Exercises

| # | File | Problem | Technique | Complexity |
|---|---|---|---|---|
| 1 | `Exer01_AddSorted.cpp` | Insert a value into a sorted list, keeping it sorted | Handle empty list, head, middle and tail | O(N) time, O(1) space |
| 2 | `Exer02_DeleteNodeWithoutHead.cpp` | Delete a node having only a pointer to it | Node copy + `delete` | O(1) time, O(1) space |
| 3 | `Exer03_ReverseLinkedList.cpp` | Reverse the list in place | Invert `next` pointers, adjust `head` and `tail` | O(N) time, O(1) space |
| 4 | `Exer04_MergeTwoSortedLists.cpp` | Merge two sorted lists into one sorted list | Relink the existing nodes | O(N + M) time, O(1) space |
| 5 | `Exer05_RemoveNthFromEnd.cpp` | Remove the n-th node counted from the end | Fast/slow pointers, one pass | O(N) time, O(1) space |

<details>
<summary><strong>Examples for each exercise</strong></summary>

### 1. Sorted Insertion
```
List: 10 -> 20 -> 30    Insert: 5     Result: 5 -> 10 -> 20 -> 30
List: 10 -> 20 -> 30    Insert: 25    Result: 10 -> 20 -> 25 -> 30
```

### 2. Delete Node Without Predecessor
```
List: 20 -> 4 -> 5 -> 19 -> 47    P points to 5    Result: 20 -> 4 -> 19 -> 47
```

### 3. Reverse a Linked List
```
Input:  head -> 20 -> 4 -> 5 -> 19 -> 47
Output: head -> 47 -> 19 -> 5 -> 4 -> 20    (tail points to 20)
```

### 4. Merge Two Sorted Lists
```
list1 = 1 -> 3 -> 5 -> 7    list2 = 2 -> 4 -> 6 -> 8
Result: 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8
```

### 5. Remove N-th Node From End
```
[1 -> 2 -> 3 -> 4 -> 5], n = 2    Result: [1 -> 2 -> 3 -> 5]
[1], n = 1                        Result: []
[1 -> 2], n = 1                   Result: [1]
```

</details>

## 💻 How to Run

Compile from the **root** of the repository (the include path is relative):

```bash
g++ -std=c++17 -Wall -Wextra -o exer01 src/Exer01_AddSorted.cpp
./exer01
```

Use the same command for the other exercises, changing the file name.

---

## ⚠️ Read the Problem Statement Carefully

- **Exercise 1:** handle the empty list, the beginning, the middle and the end, and keep `head`, `tail` and `count` correct.
- **Exercise 2:** the technique does **not** work when `P` is the last node. Explain why, and free the removed node with `delete`.
- **Exercise 3:** the reversal must be **in place** (no new list), and both `head` and `tail` must be updated.
- **Exercise 4:** **reuse the existing nodes** (do not create new ones) and return the head of the merged list.
- **Exercise 5:** do it in **one pass** with two pointers, without using `count` or `size()` to find the node.
